# z3roch / Laragen — сайт

Статичний сайт; він не опублікований в інтернеті.

## Файли
- `index.html` — сторінка українською мовою з профілями, показниками та турнірними посиланнями.
- `styles.css` — адаптивний кіберспортивний дизайн.
- `robots.txt` — базове правило для пошукових роботів.

## Публікація на GitHub Pages
1. Створи репозиторій на GitHub (наприклад `z3roch-site`) і завантаж усі файли в корінь.
2. У репозиторії відкрий Settings → Pages.
3. Вибери Deploy from a branch, гілку `main` та папку `/ (root)`, натисни Save.
4. Після появи адреси сайту заміни `https://YOUR-USERNAME.github.io/` у `index.html` на справжній URL.

Посилання на турніри, FACEIT, Steam, Twitch і YouTube включені за наданими користувачем URL. Перевір актуальність Elo перед публікацією, оскільки рейтинг змінюється.
